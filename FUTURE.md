# 🚀 Roadmap & Improvements

This document outlines planned improvements and future development directions for the Collaborative Fact-Checking Chatbot.

---

## 🧠 Functional Enhancements

### ✅ Claim System
- [ ] Add support for claim categories (e.g. political, scientific, health)
- [ ] Enable multi-user voting and consensus tracking
- [ ] Visualize claim history and weight evolution over time
- [ ] Add confidence scores alongside weights

### 📎 File Handling
- [ ] Support for more file types (e.g. HTML, Markdown, CSV)
- [ ] Preview uploaded files in the chat interface
- [ ] Allow drag-and-drop file upload

### 💬 Chat Experience
- [ ] Add typing indicator and loading animation
- [ ] Enable follow-up questions based on selected claims
- [ ] Introduce markdown rendering for bot responses
- [ ] Add support for multilingual input/output

---

## 🧪 Technical Improvements

### Backend-
- [ ] Replace mock LLM with real model integration (e.g. OpenAI, HuggingFace)
- [ ] Add persistent database for claim tracking (e.g. PostgreSQL)
- [ ] Implement authentication and user sessions
- [ ] Use Redis to store the responses generated by the backend

### Frontend
- [ ] Improve mobile responsiveness
- [ ] Add toast notifications for errors and confirmations
- [ ] Introduce dark mode toggle
- [ ] Refactor API calls with React Query or SWR
